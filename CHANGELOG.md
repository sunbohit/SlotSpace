# Changelog

## 0.1.0 - Unreleased

- M0: pinned, offline-capable STaRK-Prime export and full graph/split checks.
- M1-M4: lexical/dense/hybrid retrieval, shared schema, linking, fact extraction,
  corpus evidence, silver labels and KB-grounded role-swap construction.
- M5-M8: synthetic-data generation, training/calibration interfaces, planning,
  exact feature replay, staged tuning and hash-bound H5-controlled experiments.
- M9: stock-Vespa application, binary-context feed/query adapters, reference
  parity and validation-only measurement entry points.
- M10: distribution metadata, attribution, citation, model-status card,
  cached-input reproduction entry point and local package validation.

This is a code/reproducibility candidate, not an accepted empirical release.
No fine-tuned SlotSpace checkpoint or final test result has been published.
GPU runs, human semantic reviews and real Vespa acceptance remain pending.
The role-swap test set has 667 queries, below the original 1,000-query target.
